# เพื่อนลดน้ำหนัก 🌿

เว็บแอปภาษาไทยสำหรับช่วยติดตามการลดน้ำหนักอย่างเป็นมิตรและไม่กดดัน

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. ตั้งเป้าหมายโดยแก้ไขเป้าหมายที่ส่วน "ยินดีต้อนรับ"
3. เริ่มบันทึกข้อมูลสุขภาพประจำวันได้เลย

## ฟีเจอร์

- 📊 สรุปข้อมูลวันนี้ (น้ำหนัก, กิจกรรม, แคลอรี, นิสัย)
- ✍️ ฟอร์มบันทึกข้อมูลรายวัน
- 🍽️ บันทึกอาหารแยกตามมื้อ (เช้า/กลางวัน/เย็น/ของว่าง)
- 🔥 คำนวณแคลอรีรวมของแต่ละมื้อและรวมทั้งวัน
- ➕ เพิ่ม/แก้ไข/ลบรายการอาหารได้
- 📈 กราฟน้ำหนักรายสัปดาห์
- 📝 ประวัติการบันทึก (ลบได้)
- 🔥 สรุปแคลอรีรายวันในส่วนความคืบหน้า
- ✅ เป้าหมายเล็ก ๆ วันนี้ (Micro Goals)
- 💡 เคล็ดลับสุขภาพหมุนเวียน
- 💾 บันทึกข้อมูลใน localStorage (อยู่หลังรีเฟรช)

## เทคโนโลยี

- HTML5 + CSS3 + Vanilla JavaScript
- Chart.js (กราฟ)
- Google Fonts: Sarabun
- localStorage สำหรับเก็บข้อมูล

## หมายเหตุ

เว็บไซต์นี้เป็นเครื่องมือช่วยติดตามพฤติกรรมเท่านั้น ไม่ใช่คำแนะนำหรือการวินิจฉัยทางการแพทย์
แคลอรีของอาหารเป็นค่าประมาณ ผู้ใช้สามารถกรอกเองและแก้ไขได้
